# htmx 4

Move the vendored htmx from 2.0.10 to 4.0.0 without changing what the page
does: one markup path with and without JavaScript, the fragment/full-page
split, the 200-for-rejection contract, polling, paging and the import
upload.

## What htmx 4 changes for this app

Checked against the 4.0.0 source, not only the upgrade guide.

Unaffected:

- No renamed or removed attribute is used (`hx-disable`, `hx-disabled-elt`,
  `hx-vars`, `hx-params`, `hx-ext`, `hx-inherit`, `hx-request`).
- Nothing relies on attribute inheritance: every requesting element states
  its own `hx-target`, `hx-swap` and `hx-indicator`.
- A GET from the search `<input name="q">` still sends its own value; only
  an enclosing form stops being collected for GET.
- `input changed delay:300ms, search`, `revealed`, `load delay:2s`,
  `hx-target="this"`, `closest …`, `outerHTML`, `afterbegin`,
  `hx-encoding`, the `htmx-request` class, `HX-Redirect` and `HX-Reswap`
  all behave as before.
- History restore still sends `HX-History-Restore-Request`, so
  `isHTMXFragment` still answers it with a whole page. htmx 4 keeps no
  history cache, so the restore fires on every Back onto a pushed entry.

Changed:

1. 4xx and 5xx responses swap by default (`noSwap: [204, 304]`).
2. Requests time out client-side after 60 seconds by default. A confirm's
   window is at least `importer.IndexTimeout` (two minutes) and a large
   upload's can be longer.
3. `htmx:afterSwap` is `htmx:after:swap`, and its detail is `{ctx}`.

## Steps

1. Replace `internal/web/static/js/htmx.min.js` with the 4.0.0
   `dist/htmx.min.js`, keeping the one-line version and licence header.
2. Add `<meta name="htmx-config"
   content='{"noSwap":[204,304,"4xx","5xx"],"defaultTimeout":0}'>` to
   `document-head`. Keeping the htmx 2 status policy leaves every handler's
   200-versus-422 split as it is and keeps plain-text error bodies out of
   the controls; a zero timeout leaves the server's deadlines as the bound.
3. `edit.js`: listen for `htmx:after:swap` and read
   `event.detail.ctx.target`, which is still the pre-swap element carrying
   the id.
4. Reword every comment and note that attributes the 4xx policy to htmx's
   defaults or describes a ten-entry history cache; state the invariants in
   CLAUDE.md.
5. Pin the meta tag in a test, since deleting it leaves every handler test
   green.

## Verification

Back, paging, inline editing and its focus handling, a rejected edit, the
send and enrichment controls, and an import upload, confirm and discard.
